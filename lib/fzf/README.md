# telescope-fzf-native.nvim

A `c` port of [fzf][fzf]. It only covers the algorithm and implements few
functions to support calculating the score.

This is minimal Odin bindings for this library i (bogdanov) made.

Slightly modified, primarily added additional string length args for some functions.
